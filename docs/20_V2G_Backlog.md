# Version 2G Backlog — Auth, Roles, and Production Hardening

## Goal

Bring V1N/V1O hardening into the integrated V2 app.

## Planned Additions

- Integrated demo login
- Reader / Reviewer / Admin roles
- Role-protected review actions
- Shibboleth header mode
- Authentication events
- Admin user/role pages
- Integrated operational dashboard
- Review action audit visibility
- Production config guide

## Acceptance Criteria

- Anonymous users cannot change review decisions.
- Reviewers can accept/reject candidates.
- Readers can view reports but cannot review.
- Admins can manage users/roles.
- Shibboleth header mode can be enabled by config.
